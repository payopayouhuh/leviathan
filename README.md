# LEVIATHAN

クジラの体の仕組みを物理シミュレーションして鳴かせる、ブラウザ用の音声シンセサイザーです。見た目は [CHIMERA](https://github.com/jamesondh/chimera-vocal-synth)（Jameson Hodge, MIT）のベクター表示風デザインを参考にしています。

## 使い方

- `leviathan.html` をブラウザで開いて、「Dive in and listen」を押すと音が出ます。HTMLファイル1つで動き、サーバーは不要です。
- 右上の SPECIES で種を選び、CALLS で鳴き声を再生します。
- 左の画面を長押しすると声が出続け、上下にドラッグすると音程が変わります。
- キーボードの 1〜5 で各コール、スペースキーで持続音を出せます。
- CONTROLS の「2」ページで、距離・海の環境音・再生速度・残響を変えられます。
- ヘッドホン推奨です（シロナガスクジラは低音が中心のため）。

## 収録している種

| 種 | 発声の仕組み | 主な鳴き声 |
|---|---|---|
| ザトウクジラ | 喉頭のU字ひだ＋喉頭嚢 | 歌、うめき、フープ、クライ、うなり |
| シロナガスクジラ | 同上（超低音。標準は10倍速で再生） | A→Bの歌、B / D / Z コール、52 Hz |
| マッコウクジラ | 発音唇＋頭部の油の器官で反響 | コーダ、エコーロケーション、クリーク、スロークラップ |
| シャチ | 左右2対の発音唇で2声 | パルスコール、2声コール、スクリーム、ホイッスル、エコーロケーション |

## 音の作り方（物理モデル）

- **自励振動する声帯**：左右別々の2質量モデルです。肺の圧力で押し開かれ、閉じては開くことを繰り返して音が生まれます。
- **気道の圧力波**：気管・喉頭・喉頭嚢・鼻道を格子に区切って、圧力の伝わり方をFDTD法で計算しています。画面の気道の横線1本が格子の1マスで、そのマスの圧力で光ります。
- **空気の再利用**：鳴くと空気が肺から喉頭嚢へ移り、止めると肺へ戻ります。嚢のふくらみも計算結果のとおりに描いています。
- **マッコウクジラの頭**：クリックが頭部の器官内を往復して外へ出ます。画面では、その圧力波を約100倍スローで再生しています。
- **海**：距離に応じて高音が吸収され、深海の音響チャネル（SOFAR）を通る複数の経路で反響が重なります。

## 物理計算ではない部分

- **音程**：筋肉のように声帯の張力を自動調整して、目標の音程に合わせています。画面の数値は、実際の振動から測った音程です。
- **クリックのタイミング**：マッコウクジラなどのクリックを打つタイミングは、台本で決めています。
- **音量**：出力側で全体の音量だけ自動で揃えています。
- **パラメータ**：体の寸法や鳴き声の周波数は推定値と近似値で、実測データではありません。

## 動作環境

- 最近の Chrome / Edge / Safari / Firefox を想定しています。動作確認はChromeのみです。
- リアルタイムで物理計算をしているため、古いスマートフォンでは音が途切れることがあります。
